# Simulador Auxílio-Acidente

Quiz jurídico estático para avaliação preliminar de viabilidade de ação judicial para Auxílio-Acidente, conforme art. 86 da Lei nº 8.213/91.

## Estrutura do projeto
- `index.html`: marcação e fluxo das telas (introdução, perguntas e resultado).
- `style.css`: estilos responsivos com aparência institucional e barra de progresso.
- `script.js`: lógica do quiz em JavaScript puro, sem dependências externas.

## Como executar localmente
Abra o arquivo `index.html` em seu navegador ou sirva os arquivos estáticos com qualquer servidor HTTP simples.

## Como subir no Hostinger
1. Acesse o hPanel.
2. Vá em **Gerenciador de Arquivos**.
3. Entre em `public_html`.
4. Envie os arquivos:
   - `index.html`
   - `style.css`
   - `script.js`
5. Acesse `https://seudominio.com` para ver o quiz publicado.
